# Visual reference

The owner supplied `Afterhours stats and profile screens.png` at 1536×1024. Its upper frame is Stats, ending at the divider at y=524. Its lower frame is Profile. Both were reviewed at native resolution. Dashboard, History, and Sign in use the same type, colors, spacing, and icon family.

| Reference measurement                                                                             | Implementation                                                                                                                                       |
| ------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 240 px sidebar, main content starts near x=279, 24 px right gutter                                | 240 px sidebar at 1536 px with fluid gutters at smaller desktop sizes.                                                                               |
| Navigation rows about 49 px tall, 13 px outer inset, 24 px icons                                  | 48 px navigation rows, 12 px outer inset, 25 px Lucide icons.                                                                                        |
| Main surface near `#161615`, sidebar near `#1a1a1a`, selected route near `#4c3b2c`                | These three colors are local design tokens. Backgrounds use solid colors.                                                                            |
| Warm text near `#f5efe9`, chart and metric accents around `#ffc181`, quiet taupe borders          | Text and accent tokens closely follow the reference. Secondary copy uses `#c9c0b6` for readable contrast, and borders use `#8c8379`.                 |
| Rounded sans faces with headings around 48 px, panel titles around 28 px, and compact data labels | Nunito variable with 49 px and 28 px desktop heading caps. The supplied display faces had no confirmed name and the visible headings are sans-serif. |
| Stats grid about 695:520, Profile grid about 860:355, 18–20 px gaps                               | Desktop proportions follow the panels, with 18 px gaps and 11 px card corners. The layouts stack below 1024 px.                                      |
| 56 px rank art, 188–193 px square album art, 128 px round profile avatar                          | 56 px desktop rank art, a square four-column album grid, and a 128 px avatar cap with cover crops.                                                   |

The supplied art appears in data slots. Live covers come directly from approved Last.fm CDN URLs. Live avatars come from GitHub and use initials when a supported avatar URL is absent. Stats adds a keyboard-accessible daily table and panels for top tracks and albums. Ranked panels can grow past four entries. Profile shows automatically ranked monthly albums, a month-to-date recap, and the real sign-out action. Account controls and preferences sit below the reference panels. The private four-route navigation omits the reference's Connections entry. Nunito letterforms, flat backgrounds, variable chart labels, and reference artwork versus live covers account for visible differences. The reference contains no ambient mascot or record. The Profile motion control also applies to UI transitions, and system reduced motion suppresses transitions independently.
